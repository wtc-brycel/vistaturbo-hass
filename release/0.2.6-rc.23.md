# Vista Turbo RS232 0.2.6 RC23

RC23 adds automatic compatibility with Lantronix and other legacy serial servers that expose the VISTA RS-232 channel through Telnet-mode TCP.

- Detect Telnet IAC negotiation automatically while preserving transparent raw TCP behavior when no Telnet control traffic is present.
- Consume Telnet `WILL`, `WONT`, `DO`, `DONT`, one-byte commands, and subnegotiation before data reaches the VISTA frame parser.
- Handle the observed Lantronix startup sequence `FF FB 01 FF FB 03` without treating it as a corrupt VISTA frame or triggering recovery synchronization.
- Refuse server ECHO, accept SUPPRESS-GO-AHEAD, and refuse unsupported Telnet options.
- Preserve Telnet parser state across arbitrarily fragmented TCP reads.
- Escape and unescape literal `0xFF` bytes correctly once Telnet mode has been detected.
- Keep VISTA RX/TX byte metrics scoped to serial payload rather than Telnet control traffic.
- Add transport- and bridge-level regression coverage using the exact observed Lantronix negotiation sequence, including fragmented delivery.

No VISTA protocol, synchronization, panel-control, or state semantics are changed. Existing raw TCP serial servers continue to use the same path without requiring a new option.
