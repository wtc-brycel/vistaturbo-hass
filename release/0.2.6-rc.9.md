# Vista Turbo RS232 0.2.6 RC9

RC9 is a frontend usability fix for the Home Assistant visual editors. Panel protocol and control behavior are unchanged from RC8.

## Visual editor focus stability

Card `0.3.22` stops rebuilding the entire visual-editor shadow DOM on every Home Assistant `hass` state refresh. This fixes text fields and other editor controls losing focus while the dashboard editor is open.

The keypad editor also no longer rebuilds immediately after emitting `config-changed`, and it suppresses a redundant rebuild when Home Assistant echoes the same emitted configuration back through `setConfig()`.

The same lifecycle fix is applied to `custom:vista-event-log-card` so its editor does not steal focus either.

## Regression coverage

Chromium regression tests now verify that:

- a focused keypad-editor text field retains focus and its in-progress value across repeated Home Assistant state refreshes;
- Home Assistant echoing an emitted configuration through `setConfig()` does not replace the active control;
- the event-journal editor retains its focused input and draft value across state refreshes.

The complete backend and Chromium suites pass with the focus-stability changes.

## Frontend

Use card `0.3.22`:

```text
/local/vista-keypad-card.js?v=0.3.22
```

All RC8 control-safety behavior remains in place. Experimental panel control continues to default to disabled.
