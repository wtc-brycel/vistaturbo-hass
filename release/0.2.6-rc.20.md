# Vista Turbo RS232 0.2.6 RC20

RC20 fixes a panel reconnect loop caused by legitimate transient keypad displays that do not include an explicit partition marker.

- Attribute markerless `KD` replies to the sole serialized pending keypad transaction instead of rejecting them.
- Continue rejecting keypad replies that explicitly identify a different partition than the pending request.
- Add regression coverage using the captured `CANCEL SENT TO CENTRAL / STATION` response that triggered repeated RC19 reconnects.
