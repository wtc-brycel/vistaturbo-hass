# Vista Turbo RS232 0.2.6 RC21

RC21 fixes the reconnect loop triggered when a VISTA-128BPT enters installer programming and disables the Turbo automation interface.

- Treat `08XF` Communication Off as a deliberate programming/quiesced state instead of a broken TCP session.
- Complete the in-flight serialized keypad transaction when `08XF` is the panel's terminal response to the programming-entry keystroke.
- Keep virtual-keypad control unavailable while the panel is in programming mode.
- Treat `08XN` Communication On as program-mode exit and automatically run a full state resynchronization.
- Add regression coverage for the captured RC20 failure sequence.
