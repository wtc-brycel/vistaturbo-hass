# Vista Turbo RS232 0.2.5 RC1

This release candidate marks the first complete read-only monitoring milestone for Vista Turbo HASS.

## Status

**Read-only.** Vista Turbo RS232 does not send arm, disarm, or keypad-control commands to the alarm panel. The VISTA remains authoritative and continues to operate independently of Home Assistant.

## Included in this release candidate

- Local VISTA Turbo RS-232 monitoring through a transparent serial-to-IP connection
- Home Assistant MQTT Discovery for partition state
- Per-zone Fault, Alarm, Check, and Bypass binary sensors
- Aggregate Fault Zones, Alarm Zones, Check Zones, and Bypass Zones sensors
- Real-time VISTA system event decoding
- Programmed zone alpha descriptor retrieval
- Periodic state reconciliation
- Native partition keypad display polling over RS-232
- Exact 2 x 16 keypad text, Ready/Trouble/Armed LED state, and backlight state
- Event-triggered keypad refresh plus a 7-second polling interval by default
- Optional TransPort event receipt printing
- Packet length and checksum validation before state changes are accepted

## Keypad polling

The keypad display path has been physically validated on the test VISTA-128BPT. A normal Partition 1 transaction is:

```text
09KD10077
0AFVKD0004
29kd...
08OK009E
```

The captured 32-character display decodes to:

```text
P1   DISARMED
BYPAS-RDY TO ARM
```

## Known limits

- Only VISTA-128BPT has been tested so far.
- Arm/disarm and keypad emulation remain disabled.
- The planned 6160/6160CR-2 Home Assistant keypad UI is not part of this release candidate.
- RF low-battery and tamper events are not treated as authoritative snapshot-backed zone conditions.

This is a release candidate for continued real-panel burn-in before a stable release.
