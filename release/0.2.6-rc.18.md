# Vista Turbo RS232 0.2.6 RC18

RC18 fixes keypad and alarm control staying unavailable after RC17.

- Successful VISTA read transactions now establish that the automation interface is available.
- Explicit Communication Off still blocks control until the panel reports or re-establishes availability.
- Fixes `automation_interface_unavailable` rejections while normal AS/ZS/ZP/ZD/KD traffic is working.
