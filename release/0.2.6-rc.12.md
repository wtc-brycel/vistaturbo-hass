# Vista Turbo RS232 0.2.6 RC12

RC12 adds the issue #20 VISTA command model and semantic execution layer on top of the merged #16, #17, #18, and #19 hardening work.

- Add a canonical `VistaCommand` model with fixed four-digit PIN validation, exact three-digit zone operands, deterministic keypad parsing, bounded compilation, and explicit ambiguous/configuration-dependent classifications.
- Add the structured `vista128/control/execute` MQTT endpoint. Native core arm/disarm commands are preferred when enabled; other supported commands use the existing owned and serialized keypad transaction path.
- Preserve one logical keypad interaction across all segmented KS frames and retain one bounded local administrator audit row with exact sequence, semantic fields, actor attribution, and verification outcome.
- Keep PINs and exact sequences out of normal logs, HA state, MQTT control results, and browser events. Existing legacy keypad and partition MQTT paths remain compatible.
- Bump the bridge to `0.2.6-rc.12` and the Lovelace card to `0.3.25`.

Migration is automatic for existing SQLite audit databases. The new semantic audit columns default to empty values for historical rows. Existing control gates remain disabled by default. MQTT TLS, raw diagnostics, bounded queues, retained cleanup, and repository security boundaries are unchanged from RC11 and PR #22.
