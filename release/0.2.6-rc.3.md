# Vista Turbo RS232 0.2.6 RC3

This release candidate adds the approved adaptive Home Assistant Lovelace layout for card `0.3.15` and adds real-browser regression coverage for the frontend.

## Adaptive keypad layout

`layout: auto` is the default for both supported keypad models:

- above 520 px card-container width, the approved physical keypad facsimile is shown
- at 520 px and below, the card switches to a touchscreen-first compact layout
- `layout: physical` forces the facsimile
- `layout: compact` forces the touchscreen layout

The compact layout gives priority to the LCD, status annunciators, and a usable 4 x 4 touch grid instead of shrinking the complete physical enclosure into a miniature.

Approximate compact key dimensions validated in Chromium:

```text
390 px card: ~81 x 52 px
320 px card: ~67 x 50 px
280 px card: ~57 x 50 px
240 px card: ~47 x 50 px
```

Secondary numeric legends are hidden below 320 px before primary labels or touch targets are allowed to become too small.

## Supported models

The same adaptive renderer is used by both:

- `6160cr2` - seven compact annunciators: READY, ARMED, PWR, FIRE, SIL, SUPV, TRBL
- `6160` - READY and ARMED compact annunciators; compact function keys are labeled A/B/C/D

Future keypad models can declare their compact annunciators and function-key labels in `MODEL_PROFILES` and reuse the same responsive renderer.

## Browser regression testing

CI now renders the real custom element in Chromium and verifies:

- wide AUTO layout remains physical
- 390 px and 320 px AUTO layouts switch to compact
- minimum touch-target dimensions
- 6160CR-2 and 6160 model profiles
- forced physical and compact modes
- Home Assistant light/dark AUTO case colors
- four-column Lovelace grid sizing

The existing Python/backend test suite and JavaScript syntax validation remain enabled.

## Install the Home Assistant App

Add or refresh the custom App repository:

```text
https://github.com/wtc-brycel/vistaturbo-hass
```

Update **Vista Turbo RS232** to `0.2.6-rc.3`.

## Install the keypad card

Download the attached `vista-keypad-card.js` release asset to:

```text
/config/www/vista-keypad-card.js
```

Register it under **Settings -> Dashboards -> Resources** as a JavaScript module:

```text
/local/vista-keypad-card.js?v=0.3.15
```

Minimal adaptive CR-2 card:

```yaml
type: custom:vista-keypad-card
entity: sensor.vista_partition_1_keypad
model: 6160cr2
```

Minimal adaptive 6160 card:

```yaml
type: custom:vista-keypad-card
entity: sensor.vista_partition_1_keypad
model: 6160
```

## Real Home Assistant test targets

1. Sections dashboard at narrow, medium, and full card widths
2. Masonry dashboard rendering
3. iPhone portrait and landscape orientation changes
4. AUTO physical-to-compact switching
5. forced `layout: physical` and `layout: compact`
6. light/dark AUTO case switching
7. live LCD updates and READY/ARMED/TROUBLE state
8. CR-2 AC loss/restore, fire/silence/reset, and supervisory start/restore
9. panel TCP disconnect/reconnect and entity availability

The backend remains read-only. Arm, disarm, and keypad-control commands are not sent to the VISTA.
