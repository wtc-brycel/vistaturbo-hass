# Vista Turbo RS232 0.2.6 RC25

RC25 corrects Telnet option negotiation for real Lantronix serial servers after RC23/RC24 successfully isolated Telnet control traffic from the VISTA parser but still saw startup requests time out on hardware.

- Accept the Lantronix `WILL ECHO` offer with the standard `DO ECHO` reply instead of refusing it.
- Continue accepting `WILL SUPPRESS-GO-AHEAD` with `DO SUPPRESS-GO-AHEAD`.
- Accept a server request for client-side SUPPRESS-GO-AHEAD while continuing to refuse client-side ECHO and unknown Telnet options.
- Preserve stateful IAC filtering, subnegotiation handling, literal `0xFF` escaping, and transparent raw-TCP compatibility.
- Keep all Telnet control traffic outside the VISTA frame parser.
- Update transport- and bridge-level regression coverage for the exact Lantronix startup negotiation `FF FB 01 FF FB 03` and the corrected response `FF FD 01 FF FD 03`.

RC25 includes the non-configurable installer-programming safety interlock from RC24. No VISTA protocol framing, synchronization, panel-control, or state semantics are otherwise changed.
