# Vista Turbo RS232 0.2.6 RC24

RC24 adds a non-configurable safety interlock that prevents Vista Turbo from remotely entering VISTA installer programming through keypad emulation.

- Block any four numeric keypad digits followed by `800` before the triggering keypad frame is queued for transmission.
- Cover VISTA-20P-style `code + 800` and stop Turbo `code + 8000` one digit early.
- Apply the guard to individual virtual-keypad presses, multi-key requests, semantic commands that fall back to keypad segments, and privileged raw `KS` transmission.
- Keep a short in-memory rolling numeric history independently per partition and reset it on non-numeric keypad strokes and every new panel TCP session.
- Never store or log the preceding four-digit code; safety logging identifies only the affected partition.
- Return an immediate `installer_programming_blocked` result instead of allowing an ACK timeout or reconnect cycle.
- Do not advance the safety history for a frame that was not accepted into the bounded TX queue.
- Add regression coverage for split and multi-key attempts, per-partition isolation, reset behavior, raw-TX bypass prevention, queue-full behavior, and credential-redacted logging.

This interlock has no configuration override. Installer programming remains available from a physical keypad, where local recovery is possible if Home/Facility Automation communication is disabled.
