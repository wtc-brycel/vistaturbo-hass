# Vista Turbo RS232 0.2.6 RC1

This release candidate integrates the Home Assistant keypad UI with the read-only VISTA Turbo RS-232 bridge.

## Included

- Production 6160CR-2 and 6160 Lovelace keypad cards
- Exact two-line keypad LCD rendering from the live keypad entity
- Native Ready, Trouble, Armed, and backlight state
- CR-2 Power, Fire Alarm, Silenced, and Supervisory annunciator state
- Fire Alarm latching across detector restore until keypad reset/normalization
- Immediate keypad-entity republish after relevant VISTA real-time events
- Red, white, and dark enclosure colors for both keypad models
- `case_color: auto` as the default for both models
- Optional `day_case_color` and `night_case_color` AUTO overrides
- Default AUTO mappings of red/dark for 6160CR-2 and white/dark for 6160
- Responsive enclosure geometry that preserves aspect ratio in narrow Lovelace columns
- Narrow-container key and label scaling
- Standalone `vista-keypad-card.js` release asset for Home Assistant `/config/www`

## Home Assistant App update

The App version is `0.2.6-rc.1`, allowing Home Assistant Supervisor to detect this build as an update from 0.2.5.

The backend remains read-only. Arm, disarm, and keypad-control commands are not sent to the VISTA.

## Install the keypad card

After updating the Vista Turbo RS232 App, copy the attached `vista-keypad-card.js` release asset to:

```text
/config/www/vista-keypad-card.js
```

Register it under Settings -> Dashboards -> Resources as:

```text
/local/vista-keypad-card.js?v=0.3.13
```

Minimal CR-2 card:

```yaml
type: custom:vista-keypad-card
entity: sensor.vista_partition_1_keypad
model: 6160cr2
```

Minimal 6160 card:

```yaml
type: custom:vista-keypad-card
entity: sensor.vista_partition_1_keypad
model: 6160
```

## Status

Tested on VISTA-128BPT. GitHub Actions covers the Python bridge tests and JavaScript syntax validation. A real-panel smoke test is still recommended for AC loss/restore, fire silence/reset, and supervisory restore before treating reconstructed CR-2 annunciators as fully validated.
