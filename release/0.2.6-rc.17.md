# Vista Turbo RS232 0.2.6 RC17

RC17 fixes the availability regression introduced in RC16.

- Startup no longer imports the panel's historical event log, which could monopolize the serial session and force repeated reconnects.
- Keypad polling now stays on the partitions configured in the add-on instead of probing all eight partitions.
- Normal partition, zone, and keypad state can become available as soon as the live snapshot is valid.
- Alarm entities remain fail-safe, but no-alarm completeness now follows the partitions actually mapped by the panel instead of requiring eight keypad snapshots.

No frontend changes in this release.
