# Vista Turbo RS232 0.2.6 RC5

RC5 is a frontend-focused release. The VISTA bridge protocol and audible-state plumbing are unchanged from RC4; the matching keypad card is now `0.3.18` and adds a Home Assistant visual editor.

## Visual editor

After installing the updated JavaScript resource, Home Assistant can edit the card visually instead of showing `Visual editor not supported`.

The editor covers:

- keypad entity
- `6160cr2`, `6160`, and `firstalert` styles
- AUTO, physical, and compact layout modes
- case color plus optional day/night overrides
- optional card title and card background
- sound, key chirp, state sounds, zone chime, trouble/check, supervisory, and volume settings
- optional burglary/AUX Home Assistant entity overrides
- haptic enablement and keypress duration
- A/B/C/D function-key labels

Advanced indicator/flashing entity mappings and per-function-key colors remain available through YAML. The editor does not expose any alarm-panel control option.

## Install

Update **Vista Turbo RS232** to `0.2.6-rc.5` and replace the frontend file with the release asset:

```text
vista-keypad-card.js
```

Register or update the Lovelace resource to:

```text
/local/vista-keypad-card.js?v=0.3.18
```

Existing YAML remains valid. `sound: true` and `haptic: true` shorthand values are recognized by the visual editor.

RC5 also continues to attach `vista-keypad-simulator.html` for standalone UI/audio testing.

The bridge remains read-only. Arm, disarm, and keypad-control commands are not sent to the VISTA.
