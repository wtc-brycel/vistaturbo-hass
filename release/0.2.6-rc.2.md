# Vista Turbo RS232 0.2.6 RC2

This release candidate is the real-panel and mobile-readiness build for the read-only VISTA Turbo keypad integration.

## Included

- Production 6160CR-2 and 6160 Lovelace keypad cards
- Card version `0.3.14`
- Exact two-line keypad LCD rendering from the live keypad entity
- Native Ready, Trouble, Armed, and backlight state
- CR-2 Power, Fire Alarm, Silenced, and Supervisory annunciator state
- Red, white, and dark enclosure colors for both keypad models
- `case_color: auto` by default, with optional day/night case color overrides
- Model defaults of red/dark for 6160CR-2 and white/dark for 6160
- Responsive fixed-aspect-ratio enclosure geometry

## RC2 readiness hardening

- Redraw the LCD canvas after container or orientation changes with ResizeObserver
- Clear pressed-key feedback on pointer cancellation during mobile scrolling or gestures
- Avoid full keypad rerenders for unrelated Home Assistant entity updates
- Observe browser theme changes when Home Assistant does not expose an explicit theme mode
- Add Home Assistant grid sizing hints with a six-column minimum
- Require both the bridge MQTT availability topic and panel TCP connection for panel entity availability
- Invalidate event-derived CR-2 Power, Fire Alarm, Silenced, and Supervisory state after a panel TCP gap
- Do not infer AC power from generic panel power-up reports
- Clear a restored fire latch on a later non-fire keypad display even when an unrelated burglary zone keeps READY off
- Add focused regression tests for the above behavior

## Install the Home Assistant App

Add or refresh the custom App repository:

```text
https://github.com/wtc-brycel/vistaturbo-hass
```

Update **Vista Turbo RS232** to `0.2.6-rc.2`.

## Install the keypad card

Download the attached `vista-keypad-card.js` release asset to:

```text
/config/www/vista-keypad-card.js
```

Register it under **Settings -> Dashboards -> Resources** as a JavaScript module:

```text
/local/vista-keypad-card.js?v=0.3.14
```

Minimal CR-2 card:

```yaml
type: custom:vista-keypad-card
entity: sensor.vista_partition_1_keypad
model: 6160cr2
```

Minimal 6160 card:

```yaml
type: custom:vista-keypad-card
entity: sensor.vista_partition_1_keypad
model: 6160
```

## Real-panel test targets

The first test pass should verify:

1. Startup KD polling and exact LCD text
2. READY, ARMED, TROUBLE, and backlight behavior
3. AC loss and restore behavior for the CR-2 POWER lamp
4. Fire alarm, silence, detector restore, and panel reset behavior
5. Supervisory start and restore behavior
6. Panel TCP disconnect/reconnect and Home Assistant entity availability
7. Mobile rendering in portrait and landscape, including column resizing and touch scrolling
8. Light/dark AUTO case switching

The backend remains read-only. Arm, disarm, and keypad-control commands are not sent to the VISTA.
